# Iot-sewerage-gas-detector
IoT-based multi-gas detection and monitoring system designed for sewage-side and high-risk areas. The system monitors CO₂, H₂S, CO, NH₃, NO₂, CH₄, formaldehyde, VOCs, temperature, and humidity using an ESP32 with multiple gas sensors, providing real-time alerts and cloud-based monitoring for early hazard detection and safety improvement.
